# 星桥科技 · 虚构公司知识库

全部内容仅用于知序作品演示。公司、客户、人员、金额、联系方式、业务记录及未来计划均为虚构，不代表真实组织或企业制度。

## 公司场景

星桥科技约 120 人，为企业提供桥云服务台与交付服务。星舟是内部知识项目，青禾是虚构客户交付项目。顾宁负责人事与知识运营，周砚参与治理复核，林舟负责星舟项目，唐禾负责客户交付，陈屿负责 IT 服务，许澄负责财务运营，宋禾负责质量与风险。

资料含版本、负责人、适用场景、操作步骤、例外处理和具体案例。组织编制、项目预算及服务月报之间保留可核对关系；没有填入真实企业联系信息或私人记录。

## 3 分钟体验路线

1. 从[在线演示](https://lhui278674-ux.github.io/zhixu-knowledge/)选择员工林舟，打开「员工手册」的「入职与人事」目录，预览人事制度并收藏。
2. 在统一搜索输入「电子发票」，查看命中的 PDF 正文和第 2 页位置。也可搜「青禾」「报表导出」「预支」等具体业务词。
3. 在「问问知序」提问「新员工如何领取办公设备？」或「星舟项目的交付节点是什么？」。点击 S1 查看引用的原文位置。
4. 提问「出差住宿上限是多少？」，查看 400 元制度与 500 元试行表的冲突。资料没有提供优先级，演示不会自行选定其中一份。
5. 退出并选择管理员顾宁，在「资料入库审核」预览待审的青禾培训回访。批准后切回员工，搜索「18 份」查看新入库资料；批准前该文件不在文档检索中。
6. 在「员工注册」批准陈屿并开通文库；在「管理员变更」以顾宁发起身份变更，切换周砚复核。观察待审与生效状态及操作记录。

访客也可上传带独有标记的虚构 TXT / MD，依次体验提交、审核、搜索、问答和引用。请使用自编演示内容；在线状态保存在自己的浏览器，可点顶部「重置演示」恢复。

## 完整后端与静态演示

| 项目 | 本地完整版本 | 公开静态演示 |
| --- | --- | --- |
| 数据来源 | 自建账号与授权文库 | 固定的公开虚构资料 |
| 认证授权 | FastAPI 服务端逐请求核验 | 演示身份与浏览器筛选 |
| 检索问答 | BGE 向量 + BM25 + RRF + 重排；可选 AI | 浏览器关键词原文检索与证据摘录 |
| 文件导入 | 六种格式实际解析 | TXT / MD；六格式原件可预览文字和下载 |
| 资料审批 | 待审原件不解析，通过后处理入索引 | 浏览器状态中待审与已入库分离 |
| 存储 | SQLite、原件目录、向量与审计 | 独立 localStorage，可重置 |

名称中的「研发保密」用于展示完整后端的授权场景。这里的文件全部是公开的虚构语料，静态站点中的角色筛选不能保护文件内容。请勿把静态演示用于真实内部资料。

## 生成和升级

```powershell
.\.venv\Scripts\python.exe scripts\create_demo.py
.\.venv\Scripts\python.exe scripts\export_public_demo.py
```

生成器只读取原创内容，不打开实际应用数据库。完整版本点击「导入虚构演示」后按 manifest 版本安装或升级；旧演示库与同名文件保留 ID、成员关系，更新的虚构文件重新解析。非演示库和文件不受此流程影响，不自动向员工授权，也不创建生产演示账号。
