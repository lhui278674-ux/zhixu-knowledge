# 员工门户与管理员工作台 UI 改造记录

日期：2026-09-27，早于本次 32 份演示资料升级。

- 员工与管理员入口、页面布局和导航拆分，管理员可切换员工问答。
- 浏览器完成注册待审、管理员批准并授权、员工登录；员工不能进入管理工作台。
- 管理员实际新建目录、移动 PDF；员工目录浏览、正文搜索、收藏和最近查看可用。
- 浏览器提交虚构 TXT，审核前独有标记无搜索结果，批准并解析后可搜索、问答和引用定位。
- 两位独立管理员实际完成初始化与变更申请 / 复核；申请者没有自审操作。
- 桌面与 390 像素窄屏的文档、历史、问答、来源和管理导航检查通过；关闭抽屉不可聚焦，弹窗限制焦点。
- UI 移除静态权限规则、模型和数据流说明，保留字段、空状态、审核结果及故障反馈；技术说明留在设计和运行文档。
- 旧数据库增量迁移、原账号保留及单管理员补设第二位已验证。非空旧账号 / 文档 / 向量 / 问答的保留另外用合成迁移数据核对。

当时 21 项集成测试通过，外部生成响应在自动化中模拟。真实上游生成此次未成功；本地证据摘录及引用预览成功。私人测试账号、数据库、日志和截图不随公开仓库发布。
